# 홍보 영상 소스 (2026-10-13)

학교 홍보 영상(CapCut 편집용)의 **앞부분 23.5초**를 게임 안에서 직접 연출해 녹화한 결과물이다.
편집 프로그램 없이 **Godot의 영상 녹화 기능(Movie Maker)** 으로 뽑았다.

| 파일 | 내용 |
|---|---|
| `full_promo.mp4` | **전체 완성본(48.3초)** = 앞부분 + 뒷부분을 이어 붙인 것, 약 39MB |
| `01_intro.mp4` | 앞부분 23.5초(빌런 소개). 1920x1080, 60fps, H.264 + AAC 소리 |
| `02_outro.mp4` | 뒷부분 24.8초("그들이 격돌합니다" → 싸우는 장면 5개 → 로고) |
| `.gdignore` | Godot이 이 폴더(영상)를 불러오지 않게 하는 빈 파일 — 지우지 말 것 |

## 영상 구성 — "가짜 공익광고" 콘셉트

검은 화면 질문으로 진지하게 시작해서, 화면이 **흐려졌다 또렷해지며** 빌런을 한 명씩 소개한다.

| 시간 | 장면 | 자막 |
|---|---|---|
| 0 ~ 2.6초 | 검은 화면에 바탕체 질문 | 당신의 주위에도 이런 사람이 있나요? |
| 2.6 ~ 7초 | 놀이터 — 금쪽이가 아무도 없는 쪽으로 비비탄 발사 | 사람한테 비비탄 쏘는 금쪽이 |
| 7.5 ~ 11초 | 번화가 — 이미 한 모금 마신 주정뱅이가 한 모금 더 마시고 무지개 토 | 길거리에 토하는 사람 |
| 11.7 ~ 15초 | 악플러의 집 — 악플러가 컴퓨터 옆에 키보드를 들고 가만히 서 있음 | 집구석에서 악플 다는 사람 |
| 15.3 ~ 19초 | 번화가 2층(편의점 지붕) — 일진이 담배를 피움 | 아무 데서나 담배 피우는 사람 |
| 19.3 ~ 23.5초 | 지하철 — 지하철 아저씨가 의자 위에 단소를 들고 서 있음 | 단소로 지하철을 공연장으로 만드는 사람 |

- 장면이 넘어갈 때마다 **화면 전체가 흐려졌다가** 그 사이에 맵이 바뀐다
- 카메라는 캐릭터를 크게(맵 기본의 2.4배) 잡고 **오른쪽으로 천천히 흘러간다**
- 자막은 바탕체(Batang), 흰 글씨 + 검은 테두리, 캐릭터 머리 위 화면 가운데 근처
- HUD(체력바 등)는 없다 — 타이틀 화면의 "구경 모드"로 맵을 띄우기 때문

## 뒷부분 — "그들이 격돌합니다" (`02_outro.mp4`, 2026-10-13)

| 시간 | 장면 |
|---|---|
| 0 ~ 2.3초 | 검은 화면. "그들이"가 딱 뜨고, "격돌합니다"가 오른쪽에서 날아와 옆에 부딪힘(번쩍 + 흔들림). 앞부분 자막과 같은 바탕체 + 검은 윤곽선 |
| 2.3 ~ 4.3초 | 놀이터 — 금쪽이가 평타 3타 콤보로 일진을 날림 |
| 4.3 ~ 6.3초 | 번화가 — 악플러가 치려는 순간 주정뱅이가 먼저 맞혀 **카운터 슬로**("COUNTER" + 배경 흐림) |
| 6.3 ~ 8.3초 | 지하철 — 비비탄을 쏘는 사이 **열차**가 들이닥쳐 둘을 휩쓺 |
| 8.3 ~ 10.5초 | 헬스장 운동 — 주정뱅이가 런닝머신을 달리며 발이 자전거 바퀴 → 스포츠카 바퀴 → 로켓 신발로 바뀜(스택이 빨리 오르게 함) |
| 10.5 ~ 12.5초 | 헬스장 — 일진 담배 연기로 주정뱅이를 날림 |
| 12.5 ~ 14.5초 | 악플러의 집 — 지하철 아저씨 **단소 반격**(덤빈 악플러를 등 뒤에서 베어 날림) |
| 14.5 ~ 17.9초 | 지하철 아저씨 궁극기 컷신 — 원래 4.8초 중 **앞 3.4초만** |
| 17.9 ~ 21.3초 | 고양이 아주머니(검은 고양이) 궁극기 컷신 — 원래 3.8초 중 **앞 3.4초만** |
| 21.3 ~ 24.8초 | 게임 로고 "트러블 메이커"가 튀어나오며 등장 |

- 연출: `tools/promo/PromoOutro.gd`(글자·로고·순서), `tools/promo/PromoFights.gd`(싸움 5판 — 맵·캐릭터·자리·시각별 버튼을 표 `FIGHTS`로 적음)
- 싸움 장면은 카운터 연출·타격음·데미지 숫자가 나오게 **실제 대전 모드**로 띄우고, 팝업 인트로·일시정지 버튼·카운트다운·체력바·쿨타임 원은 숨긴다. 체력은 20배로 늘려 2초 안에 KO가 안 나게 했다
- 녹화: `--write-movie ".../02_outro.avi" --fixed-fps 60 res://tools/promo/PromoOutro.tscn` → 위와 같은 ffmpeg 변환
- 이어 붙이기: `ffmpeg -i 01_intro.mp4 -i 02_outro.mp4 -filter_complex "[0:v][0:a][1:v][1:a]concat=n=2:v=1:a=1[v][a]" -map "[v]" -map "[a]" -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a aac full_promo.mp4`

## 다시 만드는 법

문구·타이밍·위치를 바꾸고 싶으면 `tools/promo/PromoIntro.gd` 위쪽의 `@export` 값만 고치면 된다
(자막 `captions`, 장면 전환 시각 `t_swaps`, 캐릭터 자리 `*_pos`, 확대 `zoom_mult` 등).

1. 녹화 (약 2분 걸림 — 실제보다 5배쯤 느리게 돌지만 영상은 정상 속도로 나온다)

   ```bash
   "C:/Program Files (x86)/Steam/steamapps/common/Godot Engine/godot.windows.opt.tools.64.exe" --path . --write-movie "C:/Users/bitba/Videos/TroubleMakerPromo/01_intro.avi" --fixed-fps 60 res://tools/promo/PromoIntro.tscn
   ```

2. MP4로 변환 (ffmpeg — 2026-10-13 `winget install Gyan.FFmpeg`로 설치함)

   ```bash
   ffmpeg -y -i "C:/Users/bitba/Videos/TroubleMakerPromo/01_intro.avi" -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart promo/01_intro.mp4
   ```

- 녹화 원본(AVI)은 250MB가 넘어서 GitHub에 못 올린다(파일당 100MB 제한) — 그래서 MP4만 여기에 둔다
- 확인용 스냅샷이 필요하면 맨 끝에 `-- shots=<폴더>` 를 붙인다(0.5초마다 PNG). `dense=10.1` 을 더 붙이면 그 시각부터 0.5초 동안은 0.05초마다

| `tools/PromoRecorder.gd` / `.tscn` | (처음 만든 것) AI 둘이 싸우는 대전을 그대로 녹화하는 도구 — 지금 영상에는 안 씀 |
| `Timers.gd` 외 9곳 | **녹화용 시계** `Timers.now_usec()` / `now_msec()` 추가 |

### 녹화용 시계가 왜 필요했나

녹화는 실제보다 4~5배 느리게 돈다. 그런데 카운터 슬로·KO 슬로·결과 연출 등은 **벽시계(실제 시간)** 로 길이를 잰다.
그대로 녹화하면 이 연출들이 영상에서 4배 짧아진다. 그래서 `Time.get_ticks_usec()`를 쓰던 곳을
`Timers.now_usec()`로 바꿨다 — **녹화 중일 때만** "프레임 수 ÷ 60"으로 시간을 세고, **평소 플레이는 예전과 똑같다.**
바꾼 곳: `Fighter`, `CounterHitFx`, `CameraRig`, `CollisionDebugView`, `SubwaySignBoard`, `RunningKid`, `ArrestScene`, `MatchEnding`, `SkillCooldownIcon`

## 만들면서 겪은 문제 (다시 만들 때 주의)

| 증상 | 원인 | 해결 |
|---|---|---|
| 금쪽이 목이 꺾인 채 굳어 있음 | AI 조종기를 통째로 떼었다 — 이 게임은 **조종기가 캐릭터 물리를 매 프레임 돌린다**. 떼면 첫 프레임 달리던 자세로 얼어붙는다 | AI는 남기고 `is_active = false`(생각만 끔) |
| 비비탄이 안 나감 | 그네 바로 앞에 세워서 그네에 맞아 경직 | 미끄럼틀과 그네 사이 빈 땅으로 옮김 |
| 장면이 바뀔 때 하얀 바람 줄 | AI를 한 프레임 늦게 꺼서 그 사이 대시·점프를 함 | 맵을 붙이는 **그 자리에서** AI를 끔 |
| 장면이 바뀔 때 착지하는 느낌 | 캐릭터를 바닥보다 15~25px 위에 놓아 떨어지며 착지 효과가 남 | 발바닥을 딛는 면에 정확히 맞춤 |
| 번화가에서 도로 아래 돌 블록이 보임 | 확대한 화면이 땅 아래까지 비춤 | 땅을 원래 게임 화면과 **같은 높이 비율**(약 92%)에 둠 |
| 자막이 캐릭터와 겹침 | 땅을 아래로 내리면서 발치와 겹침 | 자막을 캐릭터 머리 위로. 지하철만 덜 확대(0.7배)·카메라를 바닥까지 내리고 자막을 더 위로 |
| 회색 창만 뜨고 안 꺼짐 | 스크립트 오타 → 연출이 시작도 안 됨 | 녹화 전 `--check-only`로 문법 검사(`GameState` 오류는 가짜 경보) |

- 번화가 장면은 택시·쓰레기통, 악플러의 집은 정전·엄마, 지하철은 열차를 **이 영상에서만** 멈춘다(게임은 그대로)
- 지하철 앞 기둥이 장면 끝에 화면 오른쪽에 들어오는 건 사용자 결정으로 그대로 둠
